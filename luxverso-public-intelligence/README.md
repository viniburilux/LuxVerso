# LuxVerso Public Intelligence

Página pública estática do núcleo **LuxVerso Public Intelligence**.

## Rota esperada

Quando este repositório estiver publicado via GitHub Pages, a página fica disponível em:

`/LuxVerso/luxverso-public-intelligence/`

## Conteúdo

Esta página apresenta a tese de infraestrutura de inteligência pública que conecta contratação, fornecedor, território, fluxo público e evidência documental. O conteúdo e a direção visual seguem o conceito **Atlas de Evidências**.

## Estrutura

- `index.html`: documento de entrada estático.
- `assets/`: JavaScript e CSS da build.
- `media/`: ativos visuais auto-hospedados para que a página não dependa do ambiente de desenvolvimento.

O pipeline e a evolução dos dados podem ser acompanhados em [`pncp-data-pipeline`](https://github.com/viniburilux/pncp-data-pipeline).
